**Mimir is now Goku.** It's the same product with a new name: existing installs, commands and data carry over,
and the `mimir` command keeps working as a deprecated alias of `goku`.

## Install

macOS and Linux:

```bash
curl -fsSL https://tanuj24.github.io/mimir/install.sh | sh
goku start
```

Windows (PowerShell):

```powershell
irm https://tanuj24.github.io/mimir/install.ps1 | iex
goku start
```

Or run it with Docker directly — see **[all installation options](https://tanuj24.github.io/mimir/install.html)**.
